# Al-Fath Clinic Manager 🏥
### نظام إدارة العيادات الذكي - متعدد الفروع (SaaS)

نظام سحابي متكامل (Enterprise Resource Planning - ERP) مصمم خصيصاً لإدارة المجمعات الطبية والعيادات التي تمتلك فروعاً متعددة. تم بناء النظام باستخدام أحدث تقنيات الويب (**React + TypeScript**) لضمان السرعة، الأمان، وتجربة المستخدم السلسة.

---

## 🎯 لماذا هذا النظام؟ (المشاكل التي يحلها)

يعالج "نظام عيادات الفتح" التحديات اليومية التي تواجه مديري العيادات والأطباء:

### 1. فوضى المواعيد وطوابير الانتظار ⏳
*   **المشكلة:** تداخل المواعيد (Double Booking)، عدم معرفة المريض بوقت انتظاره الحقيقي، والازدحام في صالة الاستقبال.
*   **الحل:**
    *   خوارزمية حجز ذكية تمنع تعارض المواعيد بناءً على ورديات الأطباء.
    *   شاشات انتظار (TV Mode) تعرض الدور الحالي لحظياً.
    *   نظام تتبع حالة المريض (في الانتظار -> عند الطبيب -> تم الكشف).

### 2. صعوبة إدارة الفروع المتعددة 🏢
*   **المشكلة:** عدم وجود قاعدة بيانات مركزية، صعوبة نقل الأطباء بين الفروع، وتشتت التقارير المالية.
*   **الحل:**
    *   قاعدة بيانات موحدة لجميع الفروع.
    *   لوحة تحكم مركزية (Super Admin) لمراقبة أداء كل فرع على حدة أو المجمع بالكامل.
    *   إمكانية تعيين جداول عمل مختلفة للطبيب في فروع مختلفة (مثلاً: السبت في فرع المعادي، الأحد في فرع مدينة نصر).

### 3. التسرب المالي والأخطاء المحاسبية 💸
*   **المشكلة:** صعوبة حساب نسب الأطباء (Fixed Salary vs Commission)، ضياع إيرادات الخدمات الإضافية، والأخطاء اليدوية في الفواتير.
*   **الحل:**
    *   نظام مالي آلي يحسب نسبة الطبيب فور إغلاق الزيارة.
    *   دعم نماذج دفع متعددة (راتب ثابت، نسبة، أو هجين).
    *   إصدار فواتير دقيقة تشمل الكشف والخدمات (سونار، تحاليل) ومنع التلاعب.

### 4. تشتت الملفات الطبية للمرضى 📂
*   **المشكلة:** الملفات الورقية التي تضيع، وعدم معرفة التاريخ المرضي للمريض عند زيارته لفرع آخر.
*   **الحل:**
    *   ملف طبي إلكتروني (EMR) موحد للمريض يمكن الوصول إليه من أي فرع.
    *   تسجيل التاريخ المرضي، الحساسية، والزيارات السابقة بضغطة زر.

## 🌟 المميزات التفصيلية للنظام

### 🇸🇦 دعم اللغة العربية والواجهة (RTL Support)
النظام ليس مجرد مترجم، بل مصمم معمارياً لدعم اللغة العربية:
*   **تغيير الاتجاه ديناميكياً:** قلب الواجهة بالكامل من اليمين لليسار عند اختيار العربية.
*   **خطوط مريحة:** استخدام خط "Cairo" للواجهة العربية لضمان الوضوح والاحترافية.
*   **تنسيق التواريخ والعملات:** دعم التنسيق المحلي (EGP, SAR, etc.).

### 🩺 مساحة عمل الطبيب (Doctor Workspace)
واجهة صممت لتقليل عدد النقرات التي يحتاجها الطبيب:
1.  **لوحة العلامات الحيوية:** تسجيل الضغط والحرارة والوزن ومقارنتها بالزيارات السابقة.
2.  **منشئ الوصفات الطبية (Rx Builder):** بحث سريع عن الأدوية، تحديد الجرعات، والطباعة الفورية.
3.  **إضافة الخدمات:** يستطيع الطبيب إضافة خدمات للفاتورة (مثل: غيار جرح، رسم قلب) مباشرة من شاشته.

### 📅 إدارة الموارد البشرية والجداول (HR & Scheduling)
*   **محرر الجداول المرئي:** واجهة سحب وإفلات لتحديد ساعات عمل الأطباء في كل فرع.
*   **كشف التضارب:** تنبيه المدير في حال تعيين ورديتين للطبيب في نفس الوقت بفرعين مختلفين.
*   **ملفات الموظفين:** إدارة بيانات التمريض، الاستقبال، والمديرين.

### 🌐 بوابة الحجز الإلكتروني (Patient Portal)
موقع خارجي (Public Website) يسمح للمرضى بـ:
*   استعراض الأطباء المتاحين في كل فرع وتخصصاتهم.
*   حجز الموعد أونلاين دون الاتصال بالعيادة.
*   التحقق عبر رقم الهاتف (OTP Simulation).

## 🛠 البنية التقنية (Technical Architecture)

تم تصميم النظام ليكون قابلاً للتوسع (Scalable) ومناسباً للعيادات الكبيرة:

| الطبقة (Layer) | التقنية المستخدمة | الفائدة |
|---|---|---|
| **الواجهة الأمامية** | React 18 + TypeScript | سرعة عالية وتجربة مستخدم تفاعلية (SPA). |
| **التصميم** | Tailwind CSS | تصميم متجاوب يعمل على الكمبيوتر، التابلت، والموبايل. |
| **إدارة الحالة** | Context API + Hooks | إدارة بيانات الجلسة واللغة بسلاسة. |
| **الرسوم البيانية** | Recharts | تقارير بصرية تفاعلية وسريعة التحميل. |
| **النماذج** | React Hook Form + Zod | تحقق لحظي من البيانات (Validation) ومنع الأخطاء. |

## 🚀 دليل البدء السريع (Quick Start)

### 1. المتطلبات
*   Node.js (v18 or higher)
*   NPM or Yarn

### 2. التثبيت والتشغيل
```bash
# تثبيت الحزم
npm install

# تشغيل المشروع
npm start
```

### 3. الصلاحيات الافتراضية (للتيست)
يمكنك استخدام الدخول السريع لاختبار الأدوار المختلفة:
*   **Admin:** للتحكم الكامل والتقارير.
*   **Reception:** لحجز المواعيد وإدارة الطابور.
*   **Doctor:** لتجربة شاشة الكشف والوصفات الطبية.
