# Al-Fath Clinic Manager 🏥
### نظام إدارة العيادات الذكي - متعدد الفروع

نظام سحابي (SaaS) متكامل مبني باستخدام **React** و **TypeScript** لإدارة العيادات الطبية متعددة الفروع. يهدف النظام إلى تحسين تجربة المريض، تنظيم عمل الأطباء، وإدارة الإيرادات والموارد البشرية بكفاءة عالية.

---

## 🌟 المميزات الرئيسية (Key Features)

### 1. دعم كامل للغة العربية (RTL & Localization) 🇸🇦🇪🇬
تم تصميم النظام ليعمل باللغتين العربية والإنجليزية بتبديل فوري دون إعادة تحميل الصفحة.
- **اتجاه الواجهة:** استخدام **CSS Logical Properties** (مثل `ms-`, `me-`, `border-e`) بدلاً من الاتجاهات الثابتة لضمان انعكاس التصميم تلقائياً عند تفعيل `dir="rtl"`.
- **الخطوط:** استخدام خط **Cairo** للواجهة العربية لضمان القراءة المريحة والاحترافية، و **Inter** للإنجليزية.
- **الترجمة:** استخدام مكتبة `i18next` لإدارة النصوص ديناميكياً.

### 2. إدارة المواعيد والاستقبال (Reception & Booking)
- **تقويم تفاعلي:** عرض المواعيد بنظام اليوم/الأسبوع/الشهر.
- **حجز سريع:** معالج حجز (Wizard) من 3 خطوات (تحديد المريض -> اختيار الطبيب والموعد -> التأكيد).
- **لوحة الانتظار (Queue Board):** شاشة تليفزيون (TV Mode) تعرض أسماء المرضى في الانتظار والذين يتم استدعاؤهم حالياً.

### 3. مساحة عمل الطبيب (Doctor Workspace) 🩺
واجهة متخصصة للطبيب لإدارة الكشف الطبي:
- **العلامات الحيوية (Vitals):** تسجيل الضغط، الحرارة، الوزن، إلخ.
- **التشخيص:** تسجيل الملاحظات الطبية والتشخيص (ICD-10 support ready).
- **الوصفة الطبية (E-Prescription):** منشئ وصفات طبية مع قاعدة بيانات للأدوية وقابلية للطباعة.
- **الخدمات والفوترة:** إضافة خدمات (كشف، سونار، تحاليل) للفاتورة مباشرة من داخل الكشف.

### 4. الإدارة والتقارير (Admin & Reports) 📊
- **لوحة تحكم (KPIs):** رسوم بيانية تفاعلية (Recharts) لمتابعة الإيرادات، عدد الزيارات، وأداء الفروع.
- **إدارة الفروع:** إضافة وتعديل الفروع وتعيين المديرين.
- **إدارة الموظفين:** نظام HR كامل لإدارة الأطباء، الممرضين، والاستقبال، وتحديد جداول العمل (Shifts).

### 5. بوابة المرضى (Public Booking Portal) 🌐
واجهة خارجية للمرضى تسمح لهم بحجز المواعيد أونلاين، اختيار الفرع والطبيب، وتأكيد الحجز عبر رقم الهاتف (محاكاة OTP).

## 🚀 كيفية التعامل مع اللغة العربية (RTL Implementation Details)

تم بناء النظام ليكون "مدركاً للاتجاه" (Direction-Aware). بدلاً من كتابة كود CSS خاص لكل لغة، اعتمدنا على الخصائص المنطقية:

1.  **Margin Start/End:** تم استبدال `ml-` و `mr-` بـ `ms-` و `me-`.
    *   *مثال:* أيقونة بجوار نص، في الإنجليزية تكون المسافة يساراً، وفي العربية تصبح يميناً تلقائياً.
2.  **Border Positions:** تم استبدال `border-r` بـ `border-e` (Border End).
3.  **Text Alignment:** تم استبدال `text-left` و `text-right` بـ `text-start` و `text-end`.

### مثال من الكود (`Sidebar.tsx`):
```tsx
// Active Indicator Strip
<div className={clsx(
    "absolute top-1/2 -translate-y-1/2 w-1 h-8 bg-primary-600",
    direction === 'rtl' ? "end-0 rounded-s-full" : "start-0 rounded-e-full"
)} />
```

## 👨‍💻 الأدوار والصلاحيات (Roles)

يحتوي النظام على أدوار محددة، تظهر واجهات مختلفة بناءً على الدور:
1.  **ADMIN:** وصول كامل لجميع الإعدادات والتقارير المالية.
2.  **BRANCH_MANAGER:** وصول لبيانات وموظفي الفرع المخصص له فقط.
3.  **DOCTOR:** الوصول لجدول مواعيده وملفات المرضى ومساحة العمل الطبية.
4.  **RECEPTIONIST:** الوصول لحجز المواعيد، لوحة الانتظار، والتحصيل المالي البسيط.
5.  **NURSE:** الوصول لتسجيل العلامات الحيوية (Vitals) قبل دخول المريض للطبيب.
